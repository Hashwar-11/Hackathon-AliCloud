# Pakistani Data Collection Plan

## Objective

Collect confirmed electricity theft cases from Pakistani sources.

## Sources

- IESCO
- LESCO
- FESCO
- GEPCO
- MEPCO
- PESCO
- HESCO
- NEPRA
- FIR Records
- Newspaper Reports
- DISCO Press Releases

## Required Fields

Case ID
Area
City
DISCO
Theft Type
Date
Source
Source Link
Confirmed Theft

## Goal

Minimum 50 confirmed theft cases.

Preferred 100+ confirmed cases.
