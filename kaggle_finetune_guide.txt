### Cell 3: Verify Files

```python
import os

# Check critical files
files_to_check = [
    "src/training/finetune_pakistan.py",
    "models/checkpoints/residential_model_best.pt",
    "config/config.yaml",
    "data/raw/pakistan/pakistan_combined_synthetic.csv",
    "data/processed/X_train.npy"
]

for f in files_to_check:
    exists = os.path.exists(f)
    print(f"{'✓' if exists else '✗'} {f}")
    
if not all(os.path.exists(f) for f in files_to_check):
    raise RuntimeError("Missing files! Check dataset upload.")
```

### Cell 4: Run Fine-Tune

```python
import subprocess
import sys

# Run the fine-tune script
result = subprocess.run(
    [sys.executable, "-m", "src.training.finetune_pakistan", 
     "--config", "config/config.yaml"],
    capture_output=True,
    text=True
)

print("STDOUT:")
print(result.stdout)
print("\nSTDERR:")
print(result.stderr)
print(f"\nReturn code: {result.returncode}")
```

### Cell 5: Evaluate Fine-Tuned Model

```python
# Run stage 5 transfer evaluation
result = subprocess.run(
    [sys.executable, "-m", "src.experiments.stage5_transfer",
     "--config", "config/config.yaml",
     "--target_csv", "data/raw/pakistan/pakistan_combined_synthetic.csv"],
    capture_output=True,
    text=True
)

print("STDOUT:")
print(result.stdout)
print("\nSTDERR:")
print(result.stderr)
```

### Cell 6: Download Results

```python
from IPython.display import FileLink
```

## Important Notes

1. **Use GPU**: In Kaggle notebook settings, enable "GPU T4 x2"
2. **Session timeout**: Kaggle sessions timeout after 12 hours of inactivity — keep the tab open
3. **Save outputs**: Download the fine-tuned checkpoints before session ends
4. **Honest reporting**: Label results as "fine-tuned on synthetic normals"
